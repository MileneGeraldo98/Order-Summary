# 🎵 Order Summary Component

Este é um projeto de desenvolvimento de um componente de resumo de pedido (*Order Summary*), focado em aplicar boas práticas de design responsivo e estruturação semântica em desenvolvimento web.

🚀 https://milenegeraldo98.github.io/Order-Summary/

---

## 📋 Sobre o Projeto

O objetivo deste projeto foi construir um card de resumo de assinatura de plano de música altamente fluido e otimizado. O componente se ajusta dinamicamente a diferentes resoluções e orientações de tela, eliminando barras de rolagem desnecessárias e garantindo excelente usabilidade tanto em computadores quanto em dispositivos móveis.

### ✨ Funcionalidades e Ajustes Realizados:
- **Design Responsivo Completo:** Adaptado dinamicamente para viewports Mobile e Desktop através de Media Queries (`min-width` e `max-height`).
- **Recorte Inteligente de Imagem:** Utilização de `object-fit: cover` na imagem principal para reduzir a altura do topo em telas curtas sem causar distorção na ilustração.
- **Layout Fluido com Flexbox:** Distribuição inteligente do bloco interno do plano atual, alinhando automaticamente o ícone de música, os textos e empurrando o link "Change" de forma precisa para a extremidade direita.
- **Botões Dinâmicos:** Estilização de botões com efeitos sutis de transição e sombras projetadas modernas.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web fundamentais, sem dependência de frameworks externos:

- **HTML5** — Estruturação semântica do card e organização de nós de imagem e texto.
- **CSS3** — Estilização avançada com variáveis, Flexbox, efeitos de `:hover` e responsividade sob medida.
- **Git & GitHub** — Controle de versão e hospedagem da página via GitHub Pages.
- **VS Code** — Ambiente de desenvolvimento principal.

## 🚀 Como Executar o Projeto Localmente

Caso queira clonar este repositório e testá-lo em sua máquina, siga os passos abaixo:

1. Clone o repositório:
   ```bash
   git clone https://github.com
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd Order-Summary
   ```

3. Abra o arquivo `index.html` em seu navegador de preferência ou execute utilizando a extensão **Live Server** diretamente pelo VS Code.
